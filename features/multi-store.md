<div class="mc-features-hero">
    <h1>Multi-Store</h1>
    <p>Meloncart supports running multiple independent storefronts from a <strong>single installation</strong>. Each store gets its own product catalog, categories, orders, pricing rules and settings — while sharing the same backend, codebase and theme.</p>
</div>

<div class="mc-detail-body">

<div class="mc-detail-section">
    <div class="mc-detail-section__text">
        <h2>Separate Stores, One Admin</h2>
        <p>Each store operates independently. Products created in one store don't appear in another. Orders, categories, shipping methods and price rules are all <strong>scoped per store</strong>.</p>
        <p>Switch between stores using the site picker in the backend navigation. Shared resources like customer accounts, tax classes, payment gateways and order statuses remain global, so you don't have to configure them twice.</p>

        <h2>One Theme, Every Store</h2>
        <p>Your theme is shared across all stores and sites. The same pages, partials and layouts render content from whichever store the current request belongs to. No theme <strong>duplication</strong> needed — just build once and let Meloncart handle the rest.</p>

        <h2>Easy Migration</h2>
        <p>Already running a single store? Adding a second is straightforward. Create a new site group, assign your existing site to the first group, and your current data stays <strong>intact</strong>. Then start building your second store alongside the first.</p>
