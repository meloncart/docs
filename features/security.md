# Security

Meloncart is built with security as a priority. From encrypted data storage to granular user permissions, the platform provides the tools you need to keep your store and your customers' data safe.

## SSL and Page Access

Configure any page to require HTTPS, and control access by visitor type — guests, authenticated customers or both. SSL enforcement ensures sensitive pages like checkout and account management are always served over a secure connection.

## User Permissions

Control exactly what each backend user can access. Restrict permissions by area — products, orders, themes, settings — so team members only see what's relevant to their role. You can even limit order access based on order status, so a fulfillment team only sees orders that are ready to ship.

## Audit Logging

Backend user logins are automatically logged, and critical database records track which user created or last modified them. This gives you a clear audit trail for accountability and troubleshooting.

## Data Encryption

Sensitive data stored in the database is automatically encrypted by Meloncart. In the event of a database breach, encrypted fields remain protected.

## Payment Security

Meloncart never stores credit card numbers. Payment data is handled directly by your payment gateway (Stripe, PayPal, etc.) using their secure APIs, keeping card details off your server entirely. This minimizes your PCI compliance scope and reduces risk.
