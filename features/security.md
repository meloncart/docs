<div class="mc-features-hero">
    <h1>Security</h1>
    <p>Meloncart is built with security as a priority. From encrypted data storage to granular <strong>user permissions</strong>, the platform provides the tools you need to keep your store and your customers' data safe.</p>
</div>

        <h2>User Permissions</h2>
        <p>Control exactly what each backend user can access. Restrict permissions by area such as products, orders, themes and settings, so team members only see what's relevant to their <strong>role</strong>.</p>
        <p>You can even limit order access based on order status, so a fulfillment team only sees orders that are ready to ship.</p>

<div class="mc-detail-section">

        <h2>Audit Logging</h2>
        <p>Backend user logins are automatically logged, and critical database records track which user <strong>created</strong> or last <strong>modified</strong> them. This gives you a clear audit trail for accountability and troubleshooting.</p>
    </div>
    <div class="mc-detail-section__visual">

<div class="mc-detail-section">
    <div class="mc-detail-section__text">
        <h2>Data Encryption</h2>
        <p>Sensitive data stored in the database is automatically <strong>encrypted</strong> by Meloncart. In the event of a database breach, encrypted fields remain protected.</p>
    </div>
    <div class="mc-detail-section__visual">
        <img src="/features/feat-data-encryption.png" alt="Data encryption" />
    </div>
</div>

<div class="mc-detail-section">
    <div class="mc-detail-section__text">
        <h2>Payment Security</h2>
        <p>Meloncart never stores credit card numbers. Payment data is handled directly by your payment gateway (Stripe, PayPal, etc.) using their secure APIs, keeping card details off your server entirely.</p>
        <p>This minimizes your <strong>PCI compliance</strong> scope and reduces risk.</p>
    </div>
