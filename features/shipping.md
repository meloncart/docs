# Shipping

Meloncart provides flexible shipping calculation, real-time carrier integration, tracking and label printing — everything you need to get products to your customers.

## Table Rates

For straightforward shipping setups, table rates let you define flat or tiered pricing based on destination, order weight, cart subtotal or any combination. No external API needed — just configure your rates and go.

## Real-Time Carrier Rates

Connect to major shipping carriers to provide customers with live, accurate shipping quotes at checkout. Meloncart includes built-in support for:

- **UPS**
- **USPS**
- **FedEx**
- **DHL**
- **Canada Post**
- **Australia Post**

Each carrier module passes package weight, dimensions and destination to the provider's API and returns real-time rates. Additional carriers can be added through the Marketplace or by building a custom shipping type.

## Tracking

Assign tracking codes to orders — manually or automatically via label printing — and notify customers with a single click. Meloncart supports multiple tracking codes per order, so split shipments are handled cleanly.

## Shipping Labels

Generate and print shipping labels directly from the order screen. Label printing supports carrier-specific options like insurance amounts, package types and service levels, so you can handle everything without leaving the admin panel.

## Rate Customization

Need to adjust the rates returned by a carrier? Use price rules to offer free shipping on qualifying orders or specific line items. For more advanced scenarios, the shipping API lets you hook into rate calculation and modify results programmatically from a custom plugin.
