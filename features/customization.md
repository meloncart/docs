# Customization

Meloncart gives you complete control over your storefront. Every line of HTML, CSS and JavaScript is yours to write. There are no rigid templates or opinionated layouts standing in your way — just a clean foundation and a powerful API to build on.

## Theme-Driven Architecture

Your store's design and behavior live entirely in your CMS theme. Product pages, category listings, the cart, checkout flow, URL structure — it's all defined by theme templates that you control.

Use any front-end framework or approach you like. Tailwind, Bootstrap, vanilla CSS, HTMX, Alpine.js — whatever fits your workflow. Meloncart stays out of your way and lets you write the code you want.

## Start From Scratch or Use a Theme

The Fresh Theme is available to get you up and running quickly, but you're never locked into it. Start from a blank slate and build exactly the store your client needs, using Meloncart's template tags to pull in products, categories, navigation and dynamic content wherever you need it.

## Built-In Content Editing

Store operators can update page content, product descriptions and other text through a visual editor in the backend — no developer needed for day-to-day content changes. You can define multiple editable content blocks per page, giving non-technical users control over specific sections without risking the surrounding layout.

## A Clean, Well-Documented API

Meloncart provides a straightforward API for accessing products, categories, orders, customers and more from your templates. Common store functionality is handled by ready-made components that you drop into pages, while direct API calls are available when you need deeper control.

The API is designed to be readable and predictable, so you can implement custom features without digging through source code.

## Events and Hooks

Meloncart exposes 50+ event hooks across the entire commerce lifecycle — orders, cart operations, price calculations, stock changes, checkout steps and more. Listen for events to modify behavior, inject custom logic or integrate with external services without touching core code.

Events are cancellable, so you can prevent default actions like status transitions or stock operations when your business logic requires it.

## Wishlist and Save for Later

The cart system supports named carts out of the box, so implementing wishlists and save-for-later functionality uses the same proven infrastructure as the shopping cart. Guest wishlists persist in the session, and logged-in customers have their lists stored in the database across devices.

## Extend with Plugins

Need functionality beyond the core? Meloncart's plugin architecture lets you add custom fields, integrate third-party services, create new payment gateways, or modify almost any part of the system. Plugins are built on Laravel conventions, so if you know Laravel, you already know how to extend Meloncart.

Browse the Marketplace for ready-made plugins or build and distribute your own.

## File-Based Templates and Version Control

All theme files live on disk as standard files — HTML templates, CSS, JavaScript, partials — ready to open in VS Code, PhpStorm, or any editor you prefer. Use Git for version control, set up CI/CD pipelines, collaborate with your team through pull requests. Your store's codebase is treated like any other modern project.
