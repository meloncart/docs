<div class="mc-features-hero">
    <h1>Software Updates</h1>
    <p><strong>Meloncart</strong> makes updates effortless. Apply updates with a <strong>single click</strong> from the admin panel, or run them manually through Composer. Either way, your store stays current without the hassle.</p>
</div>

<div class="mc-detail-body">

<div class="mc-detail-section">
    <div class="mc-detail-section__text">
        <h2>One-Click Updates</h2>
        <p>When a new version is available, you'll see a notification in the admin panel. Click to update and Meloncart handles the rest, pulling the latest packages via Composer and running any necessary migrations behind the scenes.</p>
    </div>

<div class="mc-detail-section">
    <div class="mc-detail-section__text">
        <h2>Or Update via Composer</h2>
        <p>Prefer the command line? Update directly with Composer like any other Laravel package.</p>
        <p>Updates are published regularly and follow semantic versioning, so you know what to expect from each release.</p>
    </div>
    <div class="mc-detail-section__visual">
        <div class="mc-editor mc-editor--small" v-pre>
            <div class="mc-editor__bar">
                <span></span><span></span><span></span>
            </div>
            <div class="mc-editor__body">
                <code>$ composer update meloncart/shop-plugin</code>
                <code>$ php artisan october:migrate</code>
            </div>
        </div>
    </div>
</div>

<div class="mc-detail-section">
    <div class="mc-detail-section__text">
        <h2>Your Customizations Stay Intact</h2>
        <p>Updates never overwrite your theme files, custom plugins or configuration. Your templates, stylesheets, JavaScript and content remain untouched. Only the core package is updated.</p>
        <p>This means you can update with confidence, knowing your storefront stays exactly as you built it.</p>
